关键发现：QED 单维 ROC-AUC = 0.247（反向），但 Docking + QED (0.846) > Docking only (0.795)，
Δ = +0.051。说明单变量方向与多变量条件贡献不是一回事 — QED 单独反向，但在 Docking 基础上仍提供增量信息。
🎯 核心发现：从固定权重到数据驱动
Heuristic Fusion（固定权重）ROC-AUC = 0.359 — 固定正向加权无法处理方向差异
Docking-only（单一证据）ROC-AUC = 0.795 — 最强单维度证据
Data-driven Activity Model（Pipeline + 5×10 CV）ROC-AUC = 0.845 ± 0.089 — 学习特征方向与边际贡献

递进逻辑：固定权重 < Docking-only < Data-driven。边际信息价值 ≠ 单维方向

📋 方法学说明

条目说明
两层 BenchmarkBenchmark A（内部一致性）+ Benchmark B（外部实验数据 ChEMBL）
防数据泄漏Pipeline: SimpleImputer(median) → StandardScaler → LogisticRegression，每 fold 独立 fit
Repeated CVRepeatedStratifiedKFold(n_splits=5, n_repeats=10, random_state=42) = 50 次评估
EF@5%补充指标，105 样本中 5% ≈ 6 个分子，方差较大
